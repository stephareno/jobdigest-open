Job Digest Agent · open source

Get an email with jobs worth your time, so you never have to look for openings.

A job search agent that runs on your own GitHub account. It reads company career boards directly, plus aggregators, LinkedIn alert emails and USAJOBS, scores every posting against a profile you build in a short interview, and sends one ranked digest a day. It never applies to anything and never contacts anyone.

Get the code on GitHub Setup guide Full spec (PRD)

What arrives each morning

One email, on the days you choose, by the time you choose. Each role shows its score out of 10, the reasons in words, the stated pay, the location and work model, and a direct apply link where one exists. Every posting the agent saw, emailed or not, is logged to a Google Sheet with a status column for tracking where you applied.

How it works

Six stages. Postings flow left to right; everything about you enters from one file at the top; secrets enter from the environment and nowhere else.

about you secrets paid (model calls) engine, free

Where everything lives

Three separate parts, and nothing is stored in two of them. This is what makes the engine reusable: a different person changes one file and nothing else.

profile.yaml

Identity and preferences. The only file you write, built by the setup interview. Every field is commented.

Environment variables

Keys and IDs. In a .env file on your computer and in GitHub Actions secrets. Never in code, never in chat.

Code

Mechanism: how distance is measured, how duplicates are found, how prompts are assembled. The same for everyone.

One starter list ships with the repository: about 4,700 US public companies from SEC filings plus a few thousand startups and growth-stage technology companies, with their career boards already located. It is a snapshot, not maintained for you, and you should filter it to your industries and regions, both for cost and so the digest is about your field. The setup guide spends real time on where to get lists for your field, because the agent can only read boards it knows about.

Known gap. Some large employers use systems the agent cannot read yet: iCIMS, SuccessFactors, Phenom, ClearCompany, Pinpoint, and career pages that only render with JavaScript. Roles there reach you only through an aggregator or a LinkedIn alert.

Setup, with an AI assistant

Create your own private copy with GitHub's Use this template button, then open it in a coding agent such as Claude Code or Codex, or attach README.md, docs/PRD.md and docs/SETUP_GUIDE.md to a chat with Claude or ChatGPT, and say "help me set this up". No coding experience needed. 60 to 90 minutes with none of the accounts; 20 with most.

Cost and limits

What it costs

About $7 to $21 a month in model API calls at a typical 20 to 60 scored postings a day, about 1 cent a posting.

  • Conservative high: about $45 in the first month if you load the entire starter list unfiltered, because every board's existing postings get scored once; the per-run cap spreads that over the first week or two. After that it settles to the typical range.
  • GitHub Actions: within the free tier for a private repository.
  • Adzuna, RapidAPI, USAJOBS, Gmail, Google Sheets: free at this volume.

What it doesn't do

  • Apply, write, or contact anyone.
  • Countries other than the US, without rebuilding the places file.
  • Sources that need a login. LinkedIn is covered through its alert emails.
  • Guarantee the minute of arrival; GitHub's queue adds a couple of hours to scheduled runs, and the schedule allows for it.

The model

Built and calibrated on Claude via the Anthropic API, which it requires today. All model calls go through one module; OpenAI-compatible endpoints are the first item on the public roadmap.

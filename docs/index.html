Job Digest Agent · open source

Get an email with jobs worth your time, so you never have to look for openings.

A job search agent that runs on your own GitHub account. It reads company career boards directly, plus aggregators, LinkedIn alert emails and USAJOBS, scores every posting against a profile you build in a short interview, and sends one ranked digest a day. It never applies to anything and never contacts anyone.

Get the code on GitHub Setup guide Full spec (PRD)

What arrives each morning

One email, on the days you choose, by the time you choose. Each role shows a score out of 10, the reason for the score, the stated pay, the location and work model, and an apply link. Every posting the agent saw, emailed or not, is logged to a Google Sheet with a status column for tracking where you applied.

How to set up

Designed for an AI assistant to do the work with you. Create your own private copy with GitHub's Use this template button, then attach README.md, docs/PRD.md and docs/SETUP_GUIDE.md to a chat with Claude or ChatGPT (or open the copy in Claude Code or Codex) and say "help me set this up".

No coding experience required. It takes one to two hours starting from zero, and the estimated cost is $7 to $20 a month in token use.

Cost and limits

What it costs

About $7 to $21 a month in model API calls at a typical 20 to 60 scored postings a day, about 1 cent a posting.

  • Conservative high: about $45 in the first month if you load the entire starter list unfiltered, because every board's existing postings get scored once; the per-run cap spreads that over the first week or two. After that it settles to the typical range.
  • GitHub Actions: within the free tier for a private repository.
  • Adzuna, RapidAPI, USAJOBS, Gmail, Google Sheets: free at this volume.

What it doesn't do

  • Apply, write, or contact anyone.
  • Countries other than the US, without rebuilding the places file.
  • Sources that need a login. LinkedIn is covered through its alert emails.
  • Guarantee the minute of arrival; GitHub's queue adds a couple of hours to scheduled runs, and the schedule allows for it.

The model

Built and calibrated on Claude via the Anthropic API, which it requires today. All model calls go through one module; OpenAI-compatible endpoints are the first item on the public roadmap.

How it works

The Job Digest Agent lives in your GitHub and collects postings from a variety of sources. It filters and scores them, then delivers the list to your email inbox every day you choose.

Where everything lives

Everything is in your GitHub, in three main and separate components. You only need to customize the profile.

profile.yaml

Identity and preferences. The only file you write, built by the setup interview. Every field is commented.

Environment variables

Keys and IDs. In a .env file on your computer and in GitHub Actions secrets. Never in code, never in chat.

Code

Mechanism: how distance is measured, how duplicates are found, how prompts are assembled. The same for everyone.

Where postings come from

The setup guide walks you through setting up and configuring a variety of sources. The more you have, the more job opportunities you'll get, but costs can also go up. Setup asks you questions to help you filter sources so you can be efficient.

The repository includes a starter list with over 5,000 companies, from public US companies to startups and growth-stage technology companies, with their career boards already located. This is not all-encompassing, and depending on your industry you may want to filter it or add more companies to it.

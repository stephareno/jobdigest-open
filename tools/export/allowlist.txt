# PUB-07a: the files the public template ships. One path or glob per line,
# relative to the repo root, read by tools/export/export_public.py.

#   path        one file
#   dir/        every tracked file under dir
#   *.py        a glob; * never crosses a "/"
#   !pattern    takes back files an earlier line matched (used only to carve
#               exceptions out of a glob; there is no separate denylist)
